Appodhaan retentive timer use pannalaam.

Adhe mixing tank. Adhe muppadhu-second preset. Indha murai retentive timer vechu paakkalaam.

Mixing Run OFF aagum. Mixer output-um OFF aagum. Timer count pannuradhu ninnudum.

Aanaa elapsed time zero-ku pogaadhu. Pathinainju second-la appadiye irukkum.

Inga mixer ninnuduchu. Timer mattum count pannitte irukkum-nu purinjukka vendaam.

Timer-um count pannuradhai niruthum. Already count pannina pathinainju second-ai mattum remember pannum.

Ippo marubadiyum Start press panrom.

Mixer odum. Timer zero-lendhu aarambikkaadhu. Pathinainju second-lendhu continue aagum.

Innum pathinainju second mix pannadhum total muppadhu second complete aagum.

Timer done signal ON aagum. Namma logic Mixing Run-ai OFF panni mixer-ai stop pannum.

Naduvula mixer ninnirundha nerathai indha mixing time-la serkka maattom.
