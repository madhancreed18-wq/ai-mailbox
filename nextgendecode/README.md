# NextGenDecode (new channel)

English YouTube channel: factory machines, industrial automation, PLC, IoT/SCADA, machine troubleshooting and build tutorials – colourful whiteboard animation made in Inkstroke.
Channel: https://www.youtube.com/@NextGenDecode-c4d (separate from Factory Decode Tamil).

## Folders
| Folder | What goes in it |
| --- | --- |
| `assets/incoming/` | Asset sheets generated by ChatGPT (PNG), named exactly as requested in `mailbox/` |
| `assets/traced/` | Claude's traced versions (sprite JS + preview PNG) |
| `episodes/NN-slug/` | Scripts, voice files, cues, stills, renders per video |
| `docs/` | Channel guide, style rules, voice profile |

## Pipeline (per video)
1. Script (paragraph split) → 2. voice (owner or Google Chirp 3 HD TTS, one WAV per language) → 3. Claude aligns + builds scenes in Inkstroke → 4. stills review → 5. 1080p render → 6. upload main audio, extra languages via YouTube Studio → Languages → Dub.

## Pillars
Sensors & signals · PLC/logic · Motors & drives · IoT/SCADA · Troubleshooting & safety
