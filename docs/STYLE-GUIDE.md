# Factory Decode Tamil – visual style guide (from episode 6)

Reference channel: RealPars (youtube.com/@realpars). Owner decision: **mix** – keep our whiteboard plant + one presenter stickman, add RealPars-style teaching tools. EP05 stays as it is; this applies from the next episode (PLC counter).

## What RealPars does (observed on "What is Ladder Logic?")
- Clean flat 2D motion graphics, light grey/white backgrounds, one brand accent colour + functional green (ON/power) and red (stop/error).
- Ladder logic drawn crisply on a white card; contacts/coils turn **green** when they conduct; power flow travels across the rung.
- Every spoken noun or action makes something appear, light up or move (sync), with a new visual roughly every 3–6 s.
- Dashed pulsing boxes, spotlight and coloured highlights focus attention; short labels on coloured pill tags.
- Smooth pans / zooms on a mostly fixed stage; slide or wipe transitions only at topic changes.
- Clear branded intro bumper, small watermark, end card with a call to action.
- No on-camera presenter (we keep ours – it is our own identity).

## Our mix (what we use)
- **Left: plant (whiteboard style)** – tank, motor, push buttons, presenter who presses them.
- **Right: PLC program card (flat style)** – live ladder rungs driven by the same state machine as the plant: closed contacts and energised coils glow green; NC contacts show the slash; timer/counter boxes show PRE / ACC.
- **Focus box** – dashed pulsing box + coloured label tag on the rung or value being spoken about (orange = attention, red = "watch this change").
- **Pointer click** – cursor with click ring, for screens without the presenter (HMI / software views).
- Sans-serif (IBM Plex Sans) for program and labels; handwriting only for whiteboard notes.
- Pacing target: one meaningful visual change every 3–6 s; hold longer on values viewers must read.
- Transitions only when the topic changes; never over a press, DONE or reset.
- Own branding (not RealPars'): short "Factory Decode Tamil" intro sting, small corner watermark, subscribe end card. Do not copy their logo, colours or end card.

## Script needs (for ChatGPT)
- Write the narration so each sentence names the thing that should light up (e.g. "Count input ON aagudhu" → contact turns green).
- Mark rung numbers in the script: [R0], [R1], [R2].
- Plan 1 focus target per sentence; questions to the viewer get a pause of ~1 s.
